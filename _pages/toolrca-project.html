WHAT CHANGES AFTER THE TOOL RETURNS?

The recommendation is stable. The decision is not.

The first L3 candidate is unchanged in 99.9% of paired trajectories that both obtain a ranking. Additional interfaces change whether the agent keeps that candidate. With L2+L3, correct-to-wrong overrides rise to 9.3% of trajectories, while wrong-to-correct revisions are 3.8%.

Where does a diagnosis fail?

01 / PROCESS

No valid finish.

The agent exhausts the budget or calls an interface without meeting its input requirements.

02 / COVERAGE

The cause never enters.

The investigation does not consider the true root cause.

03 / DECISION

Considered, not chosen.

The agent rejects the correct candidate or confirms an incorrect one.

04 / NAMING

Right entity, wrong type.

A prominent symptom is mistaken for the injected fault.

Section 5.1. For Qwen3.7-Plus with L2 or L3, the true cause was considered in 84–95% of trajectories that nevertheless ended with an incorrect localization. That percentage is conditional on localization failures.
